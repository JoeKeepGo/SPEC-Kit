# Codex

Use Codex native planning, editing, terminal, worktree, subagent, review, and
GitHub capabilities inside project authority. SAGE-Kit does not require a
command wrapper or framework runtime.

Codex is expected to discover project `AGENTS.md` instructions from the project
root toward the working directory when adoption preflight confirms the current
host version and configuration do so. Use the root bootstrap for Light work,
Light review, and mechanical corrective work. Route Standard or Heavy,
materially semantic review/corrective, acceptance, and release work to the
complete Skill once per controller context. Reload after compaction or resume
when the prior content is no longer observable. Explicit invocation remains an
override and diagnostic, and is the fallback whenever adoption, current
authority, or required Skill content cannot be observed or resolved.

`AGENTS.md` is model instruction context, not operating-system containment,
path enforcement, permission proof, or evidence that an action ran.

- Prefer one controller and disjoint subagents for independent work.
- Descendants inherit the same or narrower SAGE boundary, forbidden paths,
  permission ceilings, and human gates. Pass only the compact boundary,
  authority references, and selected profile identity with the task, never the
  activation marker; do not trigger nested Skill reloads or duplicate review.
- Use project-native focused commands; avoid repeated broad suites.
- Treat terminal access as powerful but not proof of operating-system
  containment.
- Do not install or load unrelated workflow bundles merely because they exist.
- Merge, release, credentials, destructive actions, and human acceptance need
  their own authority.

Codex session state is not project truth. The active SPEC/project authority owns
normative objective, acceptance, and intent. `ACTIVE_CONTEXT` owns the compact
status/findings/blockers/next-action snapshot and references; refresh it only
with ownership and write permission, and refresh machine facts from Git,
runtimes, checks, reviews, and artifacts that own them.
