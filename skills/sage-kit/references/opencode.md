# OpenCode

OpenCode is expected to include project `AGENTS.md` instructions and expose
permitted Skills for model selection when adoption preflight confirms the
current host version and configuration do so. Use `AGENTS.md` for Light work,
Light review, and mechanical corrective work. When the Skill tool can see
SAGE-Kit, route Standard or Heavy, materially semantic review/corrective,
acceptance, and release work to the complete Skill once per controller context;
reload after compaction or resume when prior content is no longer observable.
Explicit invocation remains an override and diagnostic and is the required
fallback whenever adoption, current authority, or required Skill content cannot
be observed or resolved.

OpenCode support is configuration-driven. Map its agents and permissions to the
SAGE-Kit launch envelope, then verify the installed host version, Skill
discovery path, and permissions actually support the relied-on controls.

Use project-native commands and evidence. Configuration may narrow normal tool
paths but cannot create project authority, acceptance, or hard containment.
All descendants inherit only the same or narrower compact SAGE boundary,
authority references, and selected profile identity, never the activation
marker, without nested Skill reloads or duplicate review. Missing optional
integration is not a blocker when a safe native path exists.
