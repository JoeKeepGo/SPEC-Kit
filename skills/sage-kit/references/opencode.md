# OpenCode

OpenCode automatically includes project `AGENTS.md` instructions and exposes
discovered, permitted Skills to the model for on-demand selection by name and
description. Use `AGENTS.md` as the lightweight automatic entry. When the Skill
tool can see SAGE-Kit, route Standard or Heavy, acceptance, review, corrective,
and release work to the complete Skill without requiring `$sage-kit` in every
prompt. Explicit invocation remains an override and diagnostic, and is the
required fallback only when neither project instructions nor implicit Skill
selection is available.

OpenCode support is configuration-driven. Map its agents and permissions to the
SAGE-Kit launch envelope, then verify the installed host version, Skill
discovery path, and permissions actually support the relied-on controls.

Use project-native commands and evidence. Configuration may narrow normal tool
paths but cannot create project authority, acceptance, or hard containment.
All descendants inherit the same or narrower SAGE boundary without nested Skill
reloads or duplicate review. Missing optional integration is not a blocker when
a safe native path exists.
