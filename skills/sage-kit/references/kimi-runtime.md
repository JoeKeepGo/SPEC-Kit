# Kimi

Kimi Code CLI automatically loads project `AGENTS.md` instructions and can
select an installed prompt Skill from its `description` and optional
`whenToUse` when model invocation is enabled. Use `AGENTS.md` as the lightweight
automatic entry, then implicitly load the complete SAGE-Kit Skill for Standard
or Heavy, acceptance, review, corrective, or release work. Explicit invocation
remains an override and diagnostic.

Project instructions, Skill selection, and approval prompts do not by
themselves prove hard containment or execution. Kimi Work and other Kimi
surfaces are best-effort unless their current host documentation establishes
automatic project instructions or implicit Skill invocation; require explicit
activation only when neither capability exists.

Use Kimi's native planning and delegated work inside the launch envelope. Under
SAGE guidance, nested executable delegation is denied by default; any exception
must be explicit, bounded, and no deeper than the host/project authority
permits.

All descendants receive the same or narrower SAGE boundary without recursively
loading the Skill or repeating review. Report soft host guidance honestly and
keep project acceptance human-owned.
