# Kimi

Kimi Code CLI is expected to load project `AGENTS.md` instructions and select an
installed prompt Skill from its `description` and optional `whenToUse` when
adoption preflight confirms the current host version, configuration, and model
invocation support. Use `AGENTS.md` for Light work, Light review, and mechanical
corrective work. Load the complete SAGE-Kit Skill for Standard or Heavy,
materially semantic review/corrective, acceptance, or release work once per
controller context; reload after compaction or resume when prior content is no
longer observable. Explicit invocation remains an override and diagnostic.

Project instructions, Skill selection, and approval prompts do not by
themselves prove hard containment or execution. Kimi Work and other Kimi
surfaces are best-effort unless current version/configuration evidence
establishes automatic project instructions or implicit Skill invocation. Use
explicit activation whenever adoption, current authority, or required Skill
content cannot be observed or resolved through those routes.

Use Kimi's native planning and delegated work inside the launch envelope. Under
SAGE guidance, nested executable delegation is denied by default; any exception
must be explicit, bounded, and no deeper than the host/project authority
permits.

All descendants receive only the same or narrower compact SAGE boundary,
authority references, and selected profile identity, never the activation
marker, without recursively loading the Skill or repeating review. Report soft
host guidance honestly and keep project acceptance human-owned.
